# RailPlan

RailPlan is a frontend-only rail maintenance control-centre prototype. It demonstrates conflict detection, explainable schedule optimisation, human approvals, strategy comparison, and emergency replanning using deterministic mock schedules.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Quality checks

```bash
npm test
npm run lint
npm run typecheck
npm run build
```

No backend, authentication, database, solver, or external API is used.
